ℹ️ About NutriBot

🤖 IBM Granite LLM

NutriBot uses ibm/granite-13b-instruct-v2 via IBM watsonx.ai to generate personalized, evidence-based nutrition plans with context-aware reasoning.

🛡️ AI Ethics & Guardrails

Every response passes through a multi-layer safety system: input validation, harmful pattern detection, output sanitization, and a mandatory medical disclaimer — following the HAM (Helpful, Accurate, Mindful) framework.

🔄 Agentic AI SDLC

Built following all phases: Requirements → Design → Prompt Engineering → Generation → Validation → Output → Feedback. The AI agent autonomously orchestrates the entire pipeline.

💾 Markdown Export

Each generated plan is automatically saved as a structured .md file with YAML front-matter, timestamps, and user metadata for future reference.

🌍 Culturally Aware

Location and cultural context are factored into recommendations. Food suggestions are adapted to what is locally available and culturally appropriate.

⚕️ Medical Disclaimer

NutriBot provides educational information only. It does not replace advice from a qualified healthcare professional or registered dietitian.
